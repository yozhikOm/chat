## Why

Чат-приложение уже умеет вход, регистрацию и сессию, а бекенд отдаёт полный API для обмена сообщениями (REST + Socket.IO: newMessage, newChannel, renameChannel, removeChannel). Однако фронтенд не подключает сокет и не показывает сообщения — в панели сообщений стоит заглушка «Сообщения появятся здесь». Эта фича реализует сам чат: отображение истории, отправку сообщений в реальном времени и управление каналами.

## What Changes

- Добавить zustand-стор чата: `channels[]`, `messages[]`, `activeChannelId`, статус соединения; экшены для подписки на события сокета и эмитов.
- Подключить `socket.io-client` в адоне с версией сокета бекенда (`socket.io ^4.8.3`) и настроить Vite-прокси `'/socket.io'` с `ws: true` на `http://localhost:3000`.
- Список каналов: клик по каналу переключает активный, кнопка «+» создаёт канал; для каналов с `removable: true` — переименовать и удалить; каналы `general`/`random` (`removable: false`) только отображаются.
- Панель сообщений: рендер сообщений активного канала из истории `GET /api/v1/data` и из событий `newMessage`, автоскролл вниз, форма отправки (пустые значения отклоняются, лимит длины тела).
- Модальные окна (свои, на существующих CSS-переменных): создание канала, переименование, подтверждение удаления. Удаление активного канала переключает на первый оставшийся.
- Валидация на клиенте: имя канала 2–20 символов, тело сообщения не пустое и до 500 символов.
- Обработка сетевых сбоев: потеря соединения с сокетом не стирает сессию; панель сообщений показывает Russian-language состояние.

## Capabilities

### New Capabilities
- `chat`: real-time обмен сообщениями и управление каналами — история, отправка сообщений через Socket.IO, создание/переименование/удаление каналов, выбор активного канала, валидация ввода и поведение при сбоях соединения.

### Modified Capabilities
- `user-auth`: из требования «Authenticated view» убирается упоминание заглушки «empty message area placeholder awaiting the chat feature» — описание чат-панели переезжает в capability `chat`; сам вход/сессия не меняются.

## Impact

- **Code**: `frontend/chatApp/` — новый `src/store/chat.ts` (zustand), `src/api/socket.ts`, компоненты `ChannelList`, `MessagePane`, `MessageInput`, единый `Modal` (общие кнопки Submit/Cancel и заголовок через пропсы), `ChannelModal` (форма создания/переименования поверх общего `Modal`; подтверждение удаления использует общий `Modal` напрямую); правки `AppShell.tsx` (интеграция стора и сокета) и `App.css` (стили чата); `vite.config.ts` — прокси `/socket.io` с `ws: true`.
- **Dependencies**: `frontend/chatApp/package.json` получает `socket.io-client` (совместимую с серверной `socket.io ^4.8.3`) и `zustand`.
- **Backend API**: потребляется как есть, без изменений. REST `GET /api/v1/data` даёт историю; Socket.IO события `newMessage`, `newChannel`, `renameChannel`, `removeChannel` транслируются бекендом.
- **Config**: `vite.config.ts` — расширение dev-прокси на websocket.
